Documentation: Rules, Process & APK Creation Guide

Rules for App Upload

  • Strictly .apk file: Only compiled Android application packages are accepted (max 100 MB).
  • Strict Version Code Invariant: Android OS requires versionCode to be strictly higher than the previously installed APK (e.g., Code 1 → Code 2). Android rejects downgrades.
  • Keystore Signing Invariant: The new APK must be signed with the same keystore/debug key. A key mismatch causes Android to throw INSTALL_FAILED_UPDATE_INCOMPATIBLE.
  • Network Distribution: The backend automatically hosts the APK under /downloads/ and makes it available immediately to all connected devices.

How to Build the APK (Windows / Terminal)

1. Update version in ZezAndroid/app/build.gradle:

versionCode 2
versionName "1.0.1"

2. Build APK in PowerShell:

cd "D:\Call Log Mannager\ZezAndroid"
.\gradlew.bat assembleDebug

3. Compiled file output location:

D:\Call Log Mannager\ZezAndroid\app\build\outputs\apk\debug\app-debug.apk
